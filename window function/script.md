# Основы оконных фунций  

### Оконные функции (Window Functions) — это мощный инструмент SQL, который позволяет выполнять вычисления над набором строк, связанных с текущей строкой.

> В отличие от обычной агрегации (GROUP BY), оконные функции не схлопывают строки. Вы получаете и результат вычисления, и все детали исходной строки одновременно.

## Зачем они нужны?

### Основные задачи:
  * Вычисление нарастающих итогов (бегущая сумма).
  * Ранжирование (составление рейтингов, топ-3 в каждой категории).
  * Вычисление скользящих средних.
  * Сравнение текущей строки с предыдущей или следующей (поиск разницы во времени или цене).

### Синтаксис и структура
> Любая оконная функция вызывается через конструкцию OVER.

```sql
SELECT 
    column_name,
    FUNCTION() OVER (
        PARTITION BY ... -- Группировка (необязательно)
        ORDER BY ...     -- Сортировка (важна для рангов и сумм)
        ROWS/RANGE ...   -- Границы окна (необязательно)
    ) AS alias
FROM table;
```
> На месте FUNCTION() пишется функция, которую необходимо выполнить
  * `PARTITION BY`: Делит данные на «окна» (например, по категориям товаров или по годам). Внутри каждого окна расчет начинается заново.
  * `ORDER BY`: Определяет порядок, в котором функция «проходит» по строкам.
  * `ROWS/RANGE`: Уточняет, сколько строк «до» и «после» текущей нужно брать в расчет

### А. Агрегатные функции
> Это привычные нам функции, но примененные «в окне».

`SUM()`, `AVG()`, `COUNT()`, `MIN()`, `MAX()`

**Пример: Нарастающий итог продаж за месяц.**

### Б. Ранжирующие функции
> Помогают пронумеровать строки.

`ROW_NUMBER()`: Просто порядковый номер (1, 2, 3, 4).

`RANK()`: При совпадении значений ставит одинаковый ранг, но пропускает следующий номер (1, 2, 2, 4).

`DENSE_RANK()`: Одинаковый ранг при совпадении, но без пропусков (1, 2, 2, 3).

### В. Функции смещения (Value Functions)
> Позволяют «заглядывать» в соседние строки.

`LAG()`: Значение из предыдущей строки.

`LEAD()`: Значение из следующей строки.

`FIRST_VALUE()` / `LAST_VALUE()`: Первое или последнее значение в окне.
## Примеры

1. Из таблицы `Trip` выведите поля `company`, `id`, `time_out` и колонку `departures_so_far` с количеством рейсов этой компании от самого раннего вылета до текущей записи включительно. При одинаковом значении `time_out` более ранней считайте запись с меньшим `id`.
```sql
select company, id, time_out,
  count(id) OVER (PARTITION BY Company ORDER by time_out ASC, id ASC) as departures_so_far
from Trip
```
2. Из таблицы `Rooms` вывести поля `home_type` и `price`, а также добавить колонку `min_price_by_type`, в которой необходимо вывести минимальную стоимость жилья для текущего типа жилья (`home_type`). Для вычисления минимальной стоимости нужно использовать оконную функцию `MIN`.
```sql
select home_type, price, MIN(price) OVER (PARTITION BY home_type) as min_price_by_type
from Rooms
```
